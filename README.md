# 唱歌学日语

用本机的 Apple Music 播放日语歌，同步显示带假名、中文翻译、语法 / 词汇标注的歌词。

## 启动

双击 `唱歌学日语.command`（或在终端里 `npm start`，然后打开 http://localhost:3939）。

第一次运行时，程序会在桌面放一个带图标的「唱歌学日语」快捷方式，以后双击它即可（会打开终端并启动）。删掉它不会再自动生成；想重新生成，删除 `data/.shortcut-created` 后再启动一次。

快捷方式固定指向创建它的那份程序。如果电脑上有不止一份（比如旧位置的副本），双击图标时会先停掉正在运行的另一份，再启动自己这一份；「设置」最下方能看到当前运行的版本和程序位置。

第一次启动时 macOS 会问「是否允许控制 Music」，请点 **允许**。之后在 Apple Music 里放歌，或从界面左上角的「资料库」里选歌即可。

## 功能

- **播放**：读取本机 Apple Music 资料库和播放列表，播放 / 暂停 / 切歌 / 拖动进度都由 Apple Music 完成。
- **歌词**：播放时自动从网易云音乐、QQ 音乐匹配（英文曲名会先反查日文原名）。有逐字时间轴时按字填充，否则逐行。可在「歌词源」里手动换源或搜索。
- **两种样式**：「滚动」（Apple Music 风格）和「大字」（单句大字 + 翻译），按 `F` 切换。
- **假名**：本地词库（kuromoji）自动注音，并用歌词源的罗马音 / QQ 注音纠正实际唱法；「改读音」模式下点汉字可手动修改（仅这一句 / 本曲 / 所有歌曲）。
- **语法 / 词汇标注**：内置约 100 条语法规则；词汇释义默认中文（有道日汉词典），JLPT 级别和英文释义来自 Jisho。在「设置」里可调样式、数量、级别、释义语言；多义词会优先显示和这一句中文翻译对得上的义项；在「修改读音 / 标注」模式下点某个标注，可以在这首歌里隐藏它（再点一次恢复），鼠标停在多义词的标注上会展开其他义项的小卡，点一张即与当前的互换（自动选义可在设置里关闭）；填入 Claude API Key 后可为整首歌生成贴合语境的讲解。
- **辞书模式**：按 `D` 或点「辞书」，点击歌词里的词（可连续点选组合，或切换为按字），点「完成」加入词汇书。词汇书可导出 CSV。
- **时间对齐**：`[` / `]` 微调，或在「对齐」里开启敲击对齐。偏移按歌曲保存。

## 更新

改完代码（或 `git pull` 之后）运行：

```bash
tools/update-local.sh
```

它会让本机正在用的程序换成这份代码的最新版：正在运行的就是这一份时原地重启（同一个终端窗口，界面自动刷新），否则通过桌面快捷方式启动并替换掉另一份；最后核对运行中的版本、位置和桌面快捷方式的指向。

## 数据

所有数据（词汇书、读音修正、偏移、歌词缓存、设置）都在 `data/` 目录里，删除即重置。

## 目录

- `server/` — 本地服务：`music.js`（Apple Music 桥接）、`lyrics.js`（歌词源）、`japanese.js`（分词 / 注音 / 纠错）、`grammar.js`（语法规则）、`annotate.js`（Jisho / Claude）
- `public/` — 界面

- 仅支持 macOS（通过 Music 的脚本接口控制播放），需要 Node.js 18+。
- 歌词与词典数据来自第三方服务（网易云音乐、QQ 音乐、有道词典、Jisho）的非官方接口，仅供个人学习使用；歌词版权归原权利人所有，本仓库不包含任何歌词内容。
