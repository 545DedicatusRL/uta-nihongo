# 唱歌学日语

用本机的 Apple Music 播放日语歌，同步显示带假名、中文翻译、语法 / 词汇标注的歌词。

## 安装

需要：一台 Mac、Apple Music 资料库里有歌、[Node.js](https://nodejs.org)（装「LTS」版即可）。

打开「终端」，粘贴下面这一行，回车：

```bash
curl -fsSL https://raw.githubusercontent.com/545DedicatusRL/uta-nihongo/main/install.sh | bash
```

它会把程序装到 `~/Applications/唱歌学日语`，装好依赖，在桌面放一个「唱歌学日语」图标并启动。第一次启动时系统会问是否允许它控制「音乐」，点 **允许**。

**更新**：再运行一次同一行。只换程序文件，你的词汇书、设置和缓存（`data/` 文件夹）不动。

想装到别的位置，在前面加上 `UTA_DIR=`，例如 `curl -fsSL …/install.sh | UTA_DIR=~/uta bash`。

也可以用 git：`git clone https://github.com/545DedicatusRL/uta-nihongo.git`，然后双击里面的 `唱歌学日语.command`。

## 启动

装好以后双击桌面上的「唱歌学日语」图标。

没有图标时，双击程序文件夹里的 `唱歌学日语.command`（在终端窗口里运行，关闭窗口即退出；或在终端里 `npm start`，然后打开 http://localhost:3939)

第一次运行时，程序会在桌面放一个「唱歌学日语」图标，以后双击它即可：程序在后台启动并打开界面，不会弹出终端窗口。运行期间程序坞里有它的图标，点一下回到界面。第一次从图标启动时，系统可能会询问是否允许它访问「文稿」文件夹、控制 Music，点允许即可。

界面窗口默认用 Chrome（没有就用 Edge 等 Chromium 系浏览器）开成独立窗口；想换浏览器，在「设置 → 更多设置 → 程序」里选。

退出：在界面的「设置 → 更多设置」最下方点「退出唱歌学日语」，或在程序坞的图标上右键退出。只关掉界面窗口不会退出程序。后台运行的记录在 `data/app.log`。

桌面图标删掉后不会再自动生成；想重新生成，删除 `data/.shortcut-created` 后再启动一次。

图标固定指向创建它的那份程序。如果电脑上有不止一份（比如旧位置的副本），双击图标时会先停掉正在运行的另一份，再启动自己这一份；「更多设置」里能看到当前运行的版本和程序位置。

第一次启动时 macOS 会问「是否允许控制 Music」，请点 **允许**。之后在 Apple Music 里放歌，或从界面左上角的「资料库」里选歌即可。

## 功能

- **播放**：读取本机 Apple Music 资料库和播放列表，播放 / 暂停 / 拖动进度都由 Apple Music 完成。
- **播放列表**：在「资料库」里点一首歌，当前筛选出来的列表（「仅日文」、搜索、所选播放列表）就成为播放列表，从这首开始，播完自动接下一首。播放键两侧是「随机播放」和「播放列表」；列表里可以点任意一首跳过去，也可以开「列表循环」。顺序由本程序决定（Apple Music 每次只播一首），所以需要程序保持运行；在 Apple Music 里自己换了列表外的歌，程序就不再接管。播不了的歌会自动跳过。
- **歌词**：播放时自动从网易云音乐、QQ 音乐匹配（英文曲名会先反查日文原名）。有逐字时间轴时按字填充，否则逐行。可在「歌词源」里手动换源或搜索。
- **两种样式**：「滚动」（Apple Music 风格）和「大字」（单句大字 + 翻译），按 `F` 切换。
- **假名**：本地词库（kuromoji）自动注音，并用歌词源的罗马音 / QQ 注音纠正实际唱法；顶栏的「修改」模式下点汉字可手动修改（仅这一句 / 本曲 / 所有歌曲）。
- **语法 / 词汇标注**：内置约 100 条语法规则；词汇释义默认中文（有道日汉词典），JLPT 级别和英文释义来自 Jisho。在「设置」里可调样式、数量、级别、释义语言；多义词会优先显示和这一句中文翻译对得上的义项；在顶栏的「修改」模式下点某个标注，可以在这首歌里隐藏它（再点一次恢复），鼠标停在多义词的标注上会展开其他义项的小卡，点一张即换上它（自动选义可在设置里关闭）；填入 Claude API Key 后可为整首歌生成贴合语境的讲解。
- **记词（辞书模式）**：按 `D` 或点「记词」，点击歌词里的词（可连续点选组合，或切换为按字），点「完成」加入词汇书。词汇书可导出 CSV。
- **词汇书的记忆模式**：点词汇书里的「记忆模式」，词条会被打乱，释义、例句和翻译整块模糊；先自己回想，再把鼠标移上去点「展示释义」对答案。再点一次「记忆模式」恢复显示和默认顺序（按添加时间）。旁边的随机图标可以单独打乱 / 还原顺序。
- **时间对齐**：`[` / `]` 微调，或在「对齐」里开启敲击对齐。偏移按歌曲保存。
- **自定义与修改**: 由于歌曲中汉字的读音多样，虽然内置功能会自动修复读音，但有时仍会标注错误读音。对于错误的读音，可以在编辑模式中对假名自行更改。同时，对于有多个注释的词语，有时候会出现标注错误的情况，系统默认自动校正，如遇校正后仍错误的情况，在编辑模式也可以选择其他的注释。修改模式也可以选择注释不做选择。

## 更新

运行：

```bash
tools/update-local.sh
```

它会让本机正在用的程序换成这份代码的最新版：正在运行的就是这一份原地重启（界面自动刷新），否则通过桌面图标启动并替换掉另一份；最后核对运行中的版本、位置和桌面图标的指向。

## 数据

所有数据（词汇书、读音修正、偏移、歌词缓存、设置）都在 `data/` 目录里，删除即重置。

## 目录

- `server/` — 本地服务：`music.js`（Apple Music 桥接）、`lyrics.js`（歌词源）、`japanese.js`（分词 / 注音 / 纠错）、`grammar.js`（语法规则）、`annotate.js`（Jisho / Claude）
- `public/` — 界面

## 说明

- 仅支持 macOS（通过 Music 的脚本接口控制播放），需要 Node.js 18+。
- 歌词与词典数据来自第三方服务（网易云音乐、QQ 音乐、有道词典、Jisho）的非官方接口，仅供个人学习使用；歌词版权归原权利人所有，本仓库不包含任何歌词内容。
